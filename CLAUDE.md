# CLAUDE.md

Instructions pour Claude Code dans ce dépôt.

## Projet

Site web de Toh Tours Yucatán : excursions et circuits dans la péninsule du Yucatán (Valladolid, Yalcobá). Le site est publié gratuitement avec GitHub Pages depuis ce dépôt. Il n'y a pas encore de nom de domaine.

## Public et langues

- Voyageurs, surtout francophones. Versions en anglais et en espagnol ensuite.
- Voyageurs avec voiture : aucun transport n'est inclus.
- Les circuits de Yalcobá se font à partir de 2 personnes.
- Tutoie Coline et réponds-lui en français.

## Ce dépôt est public

Tout ce qui est ici est visible par tout le monde, y compris l'historique et les branches non fusionnées. Il ne faut donc jamais y mettre :
- les prix nets ou les commissions destinés aux agences ;
- des noms de clients, des conversations privées ou des documents administratifs ;
- des informations personnelles de Coline ou de ses proches.

Seuls les prix publics, fournis par Coline, peuvent apparaître. En cas de doute sur une information, demande-lui avant de la publier.

## Contenu

- N'invente rien : ni avis, ni chiffres, ni photos. Si une information manque, demande-la.
- Crédit photo : « © Toh Tours Yucatán ».
- Les images montrent des habitants et des familles de Yalcobá : respect de leur dignité, aucune retouche qui déforme les lieux ou les personnes.
- Ton : authentique et chaleureux, culture yucatèque telle qu'elle est aujourd'hui, sans folklore.

## Design

- Identité visuelle du flyer (à confirmer) : verts, orange, fond crème, logo, police script « Satisfy » pour les accents.
- Skill de design : `impeccable`. Commence par `/impeccable init` pour créer PRODUCT.md.
- Serveur MCP Magic UI déclaré dans `.mcp.json` (composants et animations React / Tailwind).

## Structure

- `images/logo/` : logo
- `images/` : photos des activités, converties en JPG et réduites pour le web
